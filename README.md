# Wrap-up

A Solnest AI Skool tool for Claude Code.

Say "wrap up" at the end of a Claude Code session. Claude proves every file it wrote really landed on your computer (checked against the session log, not its memory), cleans up duplicates and broken links it created, and gives you a paste-ready handoff summary so your next chat starts exactly where this one ended.

## What you need

- Claude Code (desktop app or terminal), logged in.
- No accounts, no API keys, no cost beyond your normal Claude plan.
- Python 3.9 or newer. Setup finds it, or installs it for you.

## Set it up in 3 steps

1. Copy this page's link.
2. Paste it into Claude Code and say: **set this up**
3. At the end of your next real working session, say: **wrap up**

## Good to know

- Updates install themselves. Once a day, when Claude Code starts, the tool quietly moves to the newest release. You never have to ask.
- An update never wipes your own changes. Your notes about where things live on your computer, and any change you asked Claude to make to how this tool works, stay exactly as they are.
- Want it to work differently? Just tell Claude ("always put open items first in the handoff"). It remembers.
